# Yug Restauracja

- **Dzielnica:** Wilanów
- **Typ kuchni:** gruzińska / kaukaska
- **Adres:** al. Rzeczypospolitej 4, Wilanów, Warszawa
- **Ocena:** ~4,7
- **Godziny otwarcia:** zwykle codziennie ok. 12:00–22:00 (potwierdź telefonicznie)
