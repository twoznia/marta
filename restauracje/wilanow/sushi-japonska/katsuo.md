# Katsuo Japanese Cuisine

- **Dzielnica:** Wilanów
- **Typ kuchni:** japońska / sushi
- **Adres:** ul. Stanisława Kostki Potockiego 24/B, Wilanów, Warszawa
- **Ocena:** ~4,9
- **Godziny otwarcia:** zwykle codziennie ok. 12:00–22:00 (potwierdź telefonicznie)
