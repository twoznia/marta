# Zamigo

- **Dzielnica:** Wilanów
- **Typ kuchni:** azjatycka / ramen
- **Adres:** ul. Aleksandra Gieysztora 2, Wilanów, Warszawa
- **Ocena:** ~4,5
- **Godziny otwarcia:** zwykle codziennie ok. 12:00–22:00 (potwierdź telefonicznie)

Azjatyckie smaki i rameny, dania z woka i przekąski.
